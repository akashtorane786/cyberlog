# 🔐 CyberLog – Secure Mobile Practices App

CyberLog is a Flutter-based Android application developed as part of classroom and portfolio assignments.  
The app focuses on **mobile security awareness**, **secure development practices**, and **hands-on Flutter features**.

---

## 🚀 Features Implemented

### ✅ Session 9 – Local Storage
- Saved user preferences locally using SharedPreferences
- Auto-loaded settings on app startup

### ✅ Session 10 – Permissions & Device Features
- Camera integration with runtime permission handling
- Storage and Internet permissions
- Real camera preview screen
- Secure permission awareness

### ✅ Session 11 – Native Method Channel
- Android native method channel implementation
- Fetches and displays **device model**
- Integrated into Flutter UI (Settings page)

### ✅ Session 12 – Mobile Security Awareness
- Security Checklist Screen:
    - Screen lock status (mock check)
    - Dangerous permissions indicator
    - Root / Emulator warning (placeholder)
    - Security best-practices awareness UI
- OWASP Mobile Top 10 (2024) concepts applied

## 🛡️ Security Concepts Covered
